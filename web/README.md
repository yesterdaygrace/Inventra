# Inventra Web — React Frontend

React 19 + TypeScript + Vite + Tailwind 4 + Radix UI + TanStack Query + React Router

See `../docs/frontend.md` for the full 18-screenshot gallery and feature walkthrough.

## Quick start

```bash
npm install
npm run dev     # http://localhost:5173
npm run build
npm run preview
```

Backend: `make docker-up` + `make seed` (API `:8080`, Postgres `:5432`)

Screenshots live at repo root `demo-*.png` — all 18 are tracked and rendered in `docs/frontend.md` and `README.md`.
